# Runvoke 设计规范

## 1. 设计定位

Runvoke 是面向本地开发者的桌面工作台。视觉应传达：安静、可靠、温暖、清晰、长期使用不疲劳。

- 风格：温暖的工具型极简主义。
- 密度：紧凑但不拥挤，优先保障状态和命令可读性。
- 个性：米灰纸张感、鼠尾草绿强调、深色终端形成轻微对比。
- 禁止：赛博朋克、霓虹、高饱和大色块、紫色渐变、过度圆角、玻璃拟态、卡片套卡片、无意义装饰动画。

## 2. 颜色令牌

所有常规界面颜色优先使用 `src/style.css` 中的语义变量。

| 角色 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--canvas` | `#f7f5f1` | `#171a18` | 主工作区背景 |
| `--sidebar` | `#efebe4` | `#1e2320` | 左侧导航背景 |
| `--surface` | `#fffdf9` | `#252a27` | 输入、菜单、独立表面 |
| `--surface-muted` | `#f5f1eb` | `#2d332f` | 次级控件和弱分区 |
| `--line` | `#ded8cf` | `#3b443e` | 常规分隔线 |
| `--line-strong` | `#cbc3b8` | `#535f56` | 控件边框和强调边界 |
| `--ink` | `#302d29` | `#edf0ea` | 主文字 |
| `--muted` | `#766f66` | `#afb7af` | 说明文字 |
| `--subtle` | `#9a9288` | `#858f87` | 编号、占位和弱提示 |
| `--accent` | `#637e68` | `#8db38f` | 状态点、开关、焦点 |
| `--accent-strong` | `#4f6955` | `#afd0ad` | 强调文字和主操作 |
| `--accent-soft` | `#e5ede3` | `#263a2a` | 选中与弱强调背景 |
| `--danger` | `#a9564d` | `#e4877b` | 删除、停止、错误 |
| `--danger-soft` | `#f8e9e6` | `#482a27` | 危险操作弱背景 |
| `--warning` | `#a57636` | `#e2b36f` | 启动中、停止中 |
| `--terminal` | `#282a27` | `#121513` | 日志背景 |
| `--terminal-bar` | `#343632` | `#1b211d` | 日志工具栏 |

规则：

- 不为普通组件新增孤立的十六进制颜色；先寻找语义变量。
- 白字主按钮在深色主题中改用深色文字，确保浅绿色强调面上的对比度。
- 固定浅色表面必须同时增加 `.theme-dark` 适配。
- 错误、警告、运行状态沿用既有红、赭黄、绿色语义，不交换含义。

## 3. 字体与层级

- 界面字体：`"Microsoft YaHei UI", "Segoe UI", sans-serif`。
- 命令、路径、版本、时间和编号：`"Cascadia Mono", Consolas, monospace`。
- 仅空工作区的大标题可使用 `Georgia, "Microsoft YaHei UI", serif`；普通页面标题不要使用衬线体。

推荐字号：

| 层级 | 字号 | 字重 |
|---|---:|---:|
| 页面标题 | `30–31px` | `700` |
| 区域标题 | `15–17px` | `650–700` |
| 主正文/按钮 | `12–14px` | `400–650` |
| 说明文字 | `11–12px` | `400` |
| 元数据/编号 | `9–10px` | `500–650` |
| 空状态展示标题 | `31–53px` | `600` |

- 正文行高保持 `1.5–1.7`；空状态说明可到 `1.85`。
- 中文正文避免全大写和过宽字距。
- 路径、命令和长名称使用省略号或换行，不挤压操作按钮。

## 4. 布局与间距

- 桌面窗口基准：`1120 × 720`；最小窗口：`840 × 560`。
- 首页和设置页复用统一分栏交互；侧栏允许在 `220–420px` 范围内拖拽，右侧内容区分别保留至少 `580px` 与 `520px`，窗口不足时优先收窄侧栏。
- 主内容水平留白使用 `--content-inline`，在 `28–44px` 间流动。
- 基础间距以 `4px` 为节奏，常用 `8 / 12 / 16 / 20 / 28 / 36 / 44px`。
- 使用 `min-width: 0`、`min-height: 0`、`minmax(0, 1fr)` 防止 Grid/Flex 内容撑破。
- 明确唯一滚动容器；头部、主操作和运行记录不应互相挤出可视区域。
- 设置使用全宽独立页面、纵向分类导航和独立设置面板；入口位于首页侧栏，进入设置后隐藏首页侧栏，返回工作台后恢复原有项目导航状态。

分组优先级：

1. 留白。
2. `1px` 分隔线。
3. 弱背景。
4. 独立表面或阴影，仅用于真正浮层和边界。

## 5. 形状、边框与阴影

- 常规圆角：`3–6px`。
- 圆形仅用于状态点、开关滑块等固有圆形元素。
- 控件边框：`1px solid var(--line-strong)`。
- 区域分隔：`1px solid var(--line)`。
- 常驻页面尽量无阴影；菜单、拖拽镜像、弹窗可使用柔和阴影。
- 禁止大面积 `16–24px` 圆角和所有元素胶囊化。

## 6. 组件模式

### 按钮

- 主操作：`--accent-strong` 背景，清晰动词，单个区域最多一个主按钮。
- 次操作：透明或 `--surface` 背景、细边框。
- 危险操作：`--danger` 文字或背景，停止与删除不得伪装成普通操作。
- 图标按钮必须有 `aria-label` 和 `title`；不要使用 emoji 图标。
- Hover 只能改变颜色、边框、轻微位移或阴影，不改变布局尺寸。

### 表单

- 输入高度通常 `38–42px`，圆角 `3–4px`。
- 标签、说明和错误信息建立明确层级；不要仅依靠 placeholder。
- Focus 使用强调边框和约 `3px` 的柔和外环。
- 相关字段可放在同一弱背景分区，但不要再套多层卡片。

### 开关与分段选择

- 二元开关使用 `role="switch"` 和 `aria-checked`。
- 互斥选项使用 `radiogroup`、`radio` 与 `aria-checked`。
- 选中态使用 `--accent-soft`、`--accent-strong` 和细微阴影，不使用高饱和填充。

### 列表与分组

- 项目列表保持扁平，选中项用左边线、弱背景和文字色组合表示。
- 分组标题字号小于项目名，数量使用等宽字体。
- 拖拽必须显示明确插入位置；fallback 镜像沿用当前表面和阴影。
- 右键菜单与子菜单使用统一 `3–4px` 圆角、细边框和相同字号。

### 设置页

- 使用“页面头部 + 分类导航 + 平面设置分区”。
- 每个设置项由标题、解释和右侧控件组成；纵向用分隔线组织。
- 新设置按语义加入“常规、运行与日志、应用更新”，只有类别明显不同才新增分类。
- 设置页占满窗口内容区域，不显示左侧项目边栏。
- 设置页由全宽页面主体承担纵向滚动，滚动条贴近窗口右侧；禁止在窄内容列上生成与页面边缘脱离的滚动条和空白沟槽。
- 设置分类使用与首页项目栏一致的扁平列表和左侧选中线；设置页头部、分类栏与内容区共享同一层连续、低对比度的暖色渐变画布，只靠分隔线和选中状态建立层级，不给导航套独立色块或描边卡片。
- 设置分类采用独立面板切换，右侧只显示当前选中分类的设置项，不把所有分类堆叠成长页面。
- 设置内容居中并控制最大可读宽度；最后一个分区后只保留单层底部间距，不叠加多层空白。
- 保留清晰的“返回工作台”入口；返回后恢复侧栏、项目列表及其已有状态。

### 日志终端

- 终端使用独立深色语言，不套用普通白色表面。
- 时间、流类型、正文保持固定列与等宽字体。
- 高频日志必须批量渲染、限制数量并避免布局动画。
- 链接颜色可辨识但不过亮，保留打开/复制行为提示。

## 7. 状态与反馈

- 运行：绿色；启动/停止中：赭黄；失败/危险：红色；结束：中性或柔和绿色。
- 状态同时提供文字或图形变化，不能只有颜色点。
- Toast 放在右下角，文本简短，不遮挡主操作。
- Busy 状态禁用重复操作，并使用“正在检查、正在安装、停止中”等明确文案。
- 空状态应说明下一步并提供单一主要行动。

## 8. 动效与窗口缩放

- 微交互时长：`140–220ms`，使用温和 ease。
- 弹窗、菜单、Toast 优先动画 `opacity` 与 `transform`。
- 窗口缩放期间使用流式宽度和间距，不给宽高添加滞后 transition。
- 分割线视觉宽度保持 `1px`，通过透明热区提升可拖拽性；Hover、Focus 和拖拽中使用强调色反馈，并支持方向键、Home、End 调整。
- 不做反复闪烁、持续旋转、视差或装饰性大动画。
- 在 `prefers-reduced-motion: reduce` 下将过渡和动画降到近零。

## 9. 验收清单

- 浅色和深色主题均清晰可读。
- `1120 × 720` 与 `840 × 560` 下无横向溢出、遮挡或跳变。
- 侧栏、主工作区、设置页、弹窗、菜单和终端的字号与颜色一致。
- Hover、Focus、Active、Disabled、Busy 状态齐全。
- 键盘可到达所有操作，焦点清晰，图标按钮有可访问名称。
- 项目状态、运行日志和表单数据不因纯视觉改动丢失。
- `pnpm typecheck`、`pnpm build`、`git diff --check` 通过。
