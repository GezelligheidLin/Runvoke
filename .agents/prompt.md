# Runvoke 项目提示词

你正在开发一个本地桌面项目启动器。

## 产品目标

让用户不再为多个开发项目打开大量终端窗口。用户可以为每个项目配置工作目录、启动命令和环境变量，然后在应用中启动、停止、重启进程并实时查看日志。

## 核心能力

1. 新增、编辑、删除项目配置。
2. 在后台启动项目命令，不弹出终端窗口。
3. 显示运行中、已停止、启动中和异常退出等状态。
4. 停止项目时销毁主进程及其子进程树。
5. 实时收集并展示 stdout 与 stderr 日志。
6. 将项目配置持久化到本机。
7. 后续支持系统托盘、开机启动和用 VS Code 打开项目。

## 实现原则

- 使用 Tauri 2 + Vue 3 + TypeScript + Rust。
- Vue 组件使用 Composition API 和 `<script setup lang="ts">`。
- 进程管理、文件访问和持久化等系统能力放在 Rust 侧。
- 前端只通过类型明确的 Tauri command/event 与 Rust 通信。
- 优先保证进程生命周期可靠，再扩展视觉和便利功能。
- 默认面向 Windows，同时避免不必要的平台绑定，便于未来支持 macOS 和 Linux。

## 当前阶段

核心功能已实现，包括项目配置、进程生命周期、实时日志、运行状态、系统托盘、配置持久化、VS Code 打开和开机启动。继续开发前先阅读根目录 `AGENTS.md`，修改进程管理逻辑时优先保证子进程回收和日志线程的可靠性。
