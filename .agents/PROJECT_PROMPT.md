# Runvoke 项目提示词

## 项目背景

Runvoke 是一个本地桌面项目启动器，解决多个开发项目需要分别打开终端并手工追踪其运行状态的问题。用户为项目配置工作目录、启动命令、端口和环境变量后，可在应用内管理完整进程生命周期并实时查看日志。

## 当前产品要求

1. 支持新增、编辑、删除及本地持久化项目配置，每个项目最多保存 3 条预设任务。
2. 支持常驻服务、一次任务和不持久化的临时命令，并允许同项目任务并发运行。
3. 每次执行生成独立 `runId`，展示启动中、运行中、已停止、完成和失败等状态。
4. 停止某次执行时仅销毁其主进程及完整子进程树。
5. 实时采集并按运行实例展示 stdout、stderr 和系统日志。
6. 识别日志中的 HTTP/HTTPS 链接，并允许用户在设置中选择默认浏览器打开或复制。
7. 保持系统托盘驻留、开机启动，并支持从项目操作菜单使用 VS Code 或系统文件管理器打开项目目录。
8. 选择项目目录后，从常见项目清单识别项目名称；仅在名称为空时自动填充，并保留用户手工输入。
9. 活动任务在预设命令卡片中显示状态，二次点击确认后可停止；已停止、已完成或失败的运行记录可单独或一键经确认后移除并清理日志，活动运行实例不得移除。
10. 使用 GitHub Releases 提供已签名的 Windows 更新包；应用启动后及每 30 分钟自动检查，并允许用户在设置中立即触发检查。发现新版本后应允许用户下载、安装并重启，绝不信任未签名更新。
11. 在设置中支持浅色与深色主题切换，并在本机保留用户选择；主题切换不得影响项目配置、运行状态或日志。
12. 禁用应用内原生右键菜单；项目卡片右键时显示自定义菜单，并使“编辑”准确打开该项目的编辑弹窗。
13. 应用只允许单实例运行；再次启动时不得创建额外主窗口或托盘图标，应显示、取消最小化并聚焦已有主窗口。
14. 支持拖拽调整项目列表顺序，搜索过滤时仍可在可见项目之间排序；提供明确的插入位置反馈，并将排序结果持久化到本机。
15. 支持创建、重命名、删除和折叠项目分组；项目可在表单中选择分组，也可组内或跨组拖拽，删除分组不得删除组内项目。

## 技术约束

- 使用 Tauri 2、Vue 3、TypeScript 和 Rust；包管理器固定为 pnpm。
- Vue 使用 Composition API 与 `<script setup lang="ts">`。
- 项目列表排序使用 `vue-draggable-plus`，并启用 `forceFallback` 以适配 Windows WebView2。
- 进程管理、文件访问和持久化应放在 Rust 侧；前端通过类型明确的 Tauri command 或 event 通信。
- 任务定义属于项目配置；运行状态和日志属于运行实例，禁止以项目 ID 覆盖多个并发执行。
- 项目头部固定，任务和运行记录区域使用内部滚动；运行记录必须保留足够的最小可用高度。
- 默认面向 Windows，但避免无必要的平台绑定。
- 进程管理改动优先保证子进程回收、隐藏窗口和日志线程可靠性；不得在日志或配置中暴露敏感信息。
- 更新私钥仅能存放在本机安全位置和 GitHub Secret `TAURI_SIGNING_PRIVATE_KEY`；仓库仅保存公钥、更新端点和发布工作流。
- 发布版本时必须更新 `RELEASE_NOTES.md`，说明新增功能、问题修复和体验优化，并同步用于 GitHub Release 与应用更新清单。

## AI 工作规则

- 先阅读根目录 `AGENTS.md`，保持现有技术栈、架构和编码约定。
- 前端改动至少运行 `pnpm typecheck` 与 `pnpm build`；Rust 改动至少运行 `cargo check --manifest-path src-tauri/Cargo.toml`。
- 项目需求、范围、技术栈、目录、运行方式或验收标准变化时，同步更新 `AGENTS.md`、`PROJECT_OVERVIEW.md` 和 `.agents/skills/runvoke/SKILL.md`。
